# Cooper ICP Profiles

_Research snapshot: September 19, 2026_

## Evidence boundary

Cooper publicly describes customer segments and anonymous results, but does not name customers. The only specific customer evidence found is an anonymous three-person retail P&C agency. Names below are **target prospects**, not claimed Cooper customers.

## Segmentation, Targeting, Positioning

### Segmentation

| Segment | Defining need | Cooper motion |
|---|---|---|
| Small retail agency | Up to 5 users; commercial forms from email/files | Cooper Lite, self-serve |
| Mid-market retail brokerage | Higher submission volume; AMS and carrier-portal work | Full Cooper, guided pilot |
| Wholesale brokerage | Normalize varied submissions; place risks quickly | Full Cooper, tailored deployment |
| MGA / insurer | Intake, appetite checks, underwriting and bordereaux | Enterprise deployment |
| Claims TPA | FNOL, policy checks, claim-file summarization | Enterprise claims deployment |

### Primary target

**Mid-market commercial P&C retail brokerages** with more than five users, an established AMS, multiple carrier relationships, and a service team manually moving data among email, PDFs, spreadsheets, ACORD forms, and carrier portals.

Working size hypothesis: **$1.25M-$9.9M agency revenue**, using Big “I” medium-large and large bands. Cooper has not published its own firmographic cutoff.

### Positioning

> For mid-market commercial P&C brokerages that need more submission capacity without matching headcount growth, Cooper is an AI insurance coworker that converts account documents and AMS data into reviewable submission packages and completes work across existing carrier systems. Unlike point extraction tools or generic AI, Cooper works inside the brokerage stack, checks instead of guessing, and carries work through completion.

## Primary ICP Canvas

| Dimension | Profile |
|---|---|
| Firm | Independent commercial P&C retail brokerage; more than 5 users |
| Systems | Applied Epic, AMS360, HawkSoft, or EZLynx; email; document storage; carrier portals |
| Users | CSRs, account managers, producers, placement staff |
| Buyer | COO, Head of Operations, agency principal, or Commercial Lines leader |
| Champion | Operations leader who owns submission throughput and service capacity |
| Core job | Turn fragmented account data into accurate, market-ready submissions |
| Pain | Re-keying, missing/conflicting fields, submission backlogs, slow first quote |
| Trigger | Growth without headcount, hard-market remarketing, acquisition, staff turnover |
| Success | Less handling time, faster first quote, fewer corrections, higher submission capacity |
| Qualification | Measurable workflow; representative files; daily user and sponsor; human review accepted |
| Disqualifiers | Mostly personal lines; low volume; no data access; no process owner; demands unsupervised automation |

## Sales Motion

- **Inbound:** Cooper reports strong demo and pilot demand.
- **Outbound:** Mid-market AEs and SDRs prospect, qualify, demo, and close.
- **Discovery team:** AE + Sales Engineer; customer sponsor + operations leader + daily user; AMS/IT and security join when integration depth requires them.
- **Pilot wedge:** one frequent, painful workflow with baseline volume, handling time, accuracy, and exception rate.
